NOTES FOR DEVELOPERS

This debug page showcases:
- Site configuration objects (site.*)
- Content collections (posts, pages, static_files)
- Data files access (site.data.*)
- Taxonomies (tags, categories)
- File system information
- Common liquid patterns
- Filtering, sorting, and grouping
- Date formatting and string manipulation
- Conditional logic and loops
- Random sampling and array operations

To use these patterns in your own templates:
1. Copy the liquid code blocks
2. Adapt variable names to your site structure
3. Customize the HTML/Markdown output
4. Add appropriate CSS styling
5. Test with your specific content

Common Collections Available:
- site.posts - All blog posts
- site.pages - All pages
- site.static_files - All static files
- site.data - Data from _data/ directory
- site.documents - Files in collections
- site.html_pages - HTML pages specifically

Common Filters Used:
- size - Get collection size
- where - Filter collection by property
- where_exp - Filter with custom expression
- map - Extract property from collection
- sort - Sort collection
- group_by - Group by property
- sample - Get random item(s)
- join - Join array with separator
- uniq - Remove duplicates
- concat - Concatenate arrays
- default - Provide default value
- date - Format dates
- truncate - Truncate strings
- absolute_url - Make absolute URL
- relative_url - Make relative URL
