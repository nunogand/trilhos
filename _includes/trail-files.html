{%- comment -%} Descobre o ficheiro GPX e as fotografias de uma pasta do site. Uso: {% include trail-files.html folder=page.folder cover=page.cover %} Convenção: "folder" é o NOME da pasta dentro da raiz das fotografias (por omissão /fotos, configurável com photos_root: /fotos no _config.yml). Ex.: folder: arcos_de_valdevez Define (ficam disponíveis no template que faz o include): trail_prefix pasta completa, com "/" no início e no fim (ex.: /fotos/arcos_de_valdevez/) trail_gpx_path caminho do 1.º ficheiro .gpx (por ordem alfabética), ou "" se não existir trail_photos lista de static_files com as imagens, por ordem alfabética trail_cover_path capa: "cover" (relativo à pasta) se existir, senão a 1.ª fotografia, senão "" Notas: - site.static_files ignora pastas começadas por "_" ou ".". - As extensões são comparadas em minúsculas (.JPG também é aceite). - Sub-pastas também são incluídas; para as evitar, não as crie dentro da pasta do post. {%- endcomment -%} {%- assign photos_root = site.photos_root | default: "/fotos" -%} {%- assign trail_prefix = "/" | append: photos_root | append: "/" | append: include.folder | append: "/" | replace: "///", "/" | replace: "//", "/" -%} {%- assign trail_gpx_path = "" -%} {%- assign trail_photos = "" | split: "" -%} {%- assign photo_exts = ".jpg,.jpeg,.png,.webp,.avif,.gif" | split: "," -%} {%- if include.folder -%} {%- assign trail_candidates = site.static_files | where_exp: "f", "f.path contains trail_prefix" | sort: "path" -%} {%- for f in trail_candidates -%} {%- assign ext = f.extname | downcase -%} {%- if ext == ".gpx" -%} {%- if trail_gpx_path == "" -%}{%- assign trail_gpx_path = f.path -%}{%- endif -%} {%- elsif photo_exts contains ext -%} {%- assign trail_photos = trail_photos | push: f -%} {%- endif -%} {%- endfor -%} {%- endif -%} {%- assign trail_cover_path = "" -%} {%- if include.cover -%} {%- assign trail_cover_path = trail_prefix | append: include.cover -%} {%- elsif trail_photos.size > 0 -%} {%- assign trail_cover_path = trail_photos.first.path -%} {%- endif -%}
